# FigTX figure assets

Full-resolution figures used by [FigTX](https://github.com/ZhipingWoods/FigTX), an open-source library of figures and LaTeX tables from top conference and journal papers.

- `originals/<id>.<ext>`: the original image of each FigTX gallery entry. Its paper title, authors, venue, links and source project are listed in FigTX `data/raw-gallery.json` under the same `id`.
- Sources: [topconf-paper-figure-gallery](https://github.com/qwdwqfwq/topconf-paper-figure-gallery) and [PaperGallery](https://github.com/LongHZ140516/PaperGallery), plus figures collected by FigTX.

**Copyright** of every figure stays with the original paper's authors and publishers. The images are provided for non-commercial research and educational reference, with full attribution. To request removal, open an issue at https://github.com/ZhipingWoods/FigTX/issues — we act within 72 hours.
