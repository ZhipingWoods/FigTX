# 数据管线

```
原始笔记 ──► docx ──► LaTeX ──► 编译渲染 ──► items.json ──► 前端
```

## 1. 抽取 extract_docx.py

```bash
python3 tools/extract_docx.py --docx-dir ../xhs-docx/某博主 --notes notes.json --out .
```

做的事情：

1. 逐段落读取 `word/document.xml`，还原 LaTeX 换行
2. 清掉 docx 里偶发的 `<![CDATA[...]]>` 残留
3. 识别类型：table / figure / mixed / snippet
4. 抽 caption、`\definecolor` 配色板
5. 只从「会议 + 年份」判断会议（避免 `#CVPR[话题]#` 标签污染）

输出 `data/latex/*.tex` 和 `data/raw-items.json`。

## 2. 渲染 render_tex.py

用 tectonic 把片段编译成图。片段往往不能直接编译（是论文正文节选），所以脚本做了一串自动修复：

| 问题 | 处理 |
|---|---|
| `\documentclass` / `\usepackage` 残留 | 丢弃，换成统一导言区 |
| 浮动体 `table*` 在 preview 里报错 | 降级为 `center` + `\captionof` |
| `subtable` 报 outside float | 降级为 `minipage` |
| 未定义命令 | 自动补 `\providecommand` |
| 未定义颜色 | 自动补 `\definecolor{gray}` |
| 缺图片文件 | `\includegraphics` 换成占位框 |
| 重复定义 | 去重，保留第一次 |

裁剪用 `preview` 宏包的 `tightpage`，所以渲染图没有大白边。

输出 `public/renders/<id>.webp`（1300px 宽，质量 82）。

## 3. 配图 fetch_images.py

下载原笔记配图到 `public/note-images/`，作为渲染失败时的兜底预览。

## 4. 汇总 build-data.mjs

合并上面三者 → `src/data/items.json`（会被 Vite 内联进 JS）。

## 依赖

| 工具 | 必需 | 说明 |
|---|---|---|
| tectonic | 是 | `brew install tectonic` |
| poppler (pdftoppm) | 推荐 | 质量最好；macOS 无则退回 `qlmanage` |
| cwebp | 可选 | 体积优化；`brew install webp` |
