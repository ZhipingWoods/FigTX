# 样式分类

FigTX 分两个分区，不要混在一起看。

## 一、表格（216 项，LaTeX）

按做表手法归类。

### 1. 三线表（booktabs）

基础款：`\\toprule` / `\\midrule` / `\\bottomrule`，无竖线。

### 2. 分组表头（multicolumn + cmidrule）

两组以上实验并列：`\\multicolumn{3}{c}{...}` + `\\cmidrule(lr){2-4}`。

### 3. 整行/整列底色（rowcolor / cellcolor）

需要 `\\usepackage[table]{xcolor}` + `colortbl`。黑白打印时别只靠颜色区分。

### 4. 最优值高亮

| 做法 | 效果 | 适用 |
|---|---|---|
| `\\textbf{}` | 加粗 | 最通用 |
| `\\underline{}` | 下划线 | 次优 |
| `\\cellcolor{}` | 底色 | 视觉强，占空间 |

### 5. 跨行合并（multirow）

`\\multirow{5}{*}{模型名}` 处理同模型多方法并列。

### 6. 全页宽表（table* + resizebox）

`table*` 跨双栏，`\\resizebox{\\textwidth}{!}{...}` 缩放到页宽。

## 二、图（24 项）

### 绘图样式（16 项，SciencePlots）

| 样式 | 用途 |
|---|---|
| science | 通用底子：刻度朝内、六色循环 |
| science+ieee | IEEE 双栏，黑白打印也能分辨 |
| science+nature | Nature 版式，单栏窄图 |
| + grid / notebook / scatter / sans | 版式微调 |
| + bright / vibrant / muted / retro / high-vis / light / dark | 配色切换 |
| + cjk-sc-font | 中文坐标轴 |

用法：`plt.style.use(['science', 'ieee', 'no-latex'])`

### 成图配方（8 项，paper-plot-skills）

| 配方 | 场景 |
|---|---|
| 训练曲线 + 局部放大 | 损失/指标曲线，L 形坐标轴 + inset |
| 多方法收敛曲线 | 多条曲线对比 |
| 蒸馏双图 | 主图 + 缩放对比 |
| 分组柱状图 | baseline 比较 |
| 雷达图 | 多维度能力 |
| 断轴散点 | 有离群点时保住主体分布 |
| t-SNE 聚类 | 特征空间可分性 |

每条都是可直接运行的 Python 脚本。
