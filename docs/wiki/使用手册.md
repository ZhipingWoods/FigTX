# 使用手册

## 界面速览

FigTX 是一个「选样式」的工具：左边看图，右边拿代码。

### 顶栏

| 元素 | 作用 |
|---|---|
| 搜索框 | 按标题 / caption / 会议 / LaTeX 命令搜索；按 `/` 直接聚焦 |
| 计数 | 当前筛选结果 / 全部样式 |

### 筛选条

- **类型**：表格 / 图 / 表+图 / 片段
- **已渲染**：只显示 tectonic 成功重编译的样式（画质更干净）
- **会议**：CVPR / ICLR / ACL …（来自原论文出处的「会议 + 年份」表述）

### 卡片

每张卡片左上角有来源标记：

- `LaTeX 渲染` —— 用源码重新编译出的干净结果
- `原图` —— 渲染失败时回退到原笔记配图（可能带水印、圈注）

右下角的几个小色块是这张表用到的配色。

## 详情面板

点击卡片打开：

- **左侧**：多标签预览（LaTeX 渲染 / 原图 N）
- **右侧**：caption、元信息、配色、LaTeX 源码
- **复制**：一键复制全文到剪贴板
- **下载 .tex**：保存为文件
- **原笔记**：跳到小红书原始出处

### 键盘

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `←` `k` | 上一个 |
| `→` `j` | 下一个 |
| `Esc` | 关闭 |

## 把样式用到自己论文里

1. 复制前先看源码开头的 `\definecolor{...}`，颜色定义要一起拷进导言区
2. 表格需要 `booktabs`（三线表）、`multirow`（跨行）、`colortbl`+`xcolor`（底色）
3. `\resizebox{\textwidth}{!}{...}` 会把表压到页宽，注意小字号的可读性
4. caption 里的 `\textbf{}` 是加粗标题，按目标会议要求调整
