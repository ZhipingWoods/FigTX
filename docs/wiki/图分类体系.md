# 图分类体系

FigTX 的「图」按**用途**分四类，再按**领域**和**会议**打标签。同一张图可能被多个会议反复使用，
所以卡片只展示一次，进详情页再看它常见于哪些会议。

## 一、按用途（figType）

| 类型 | 说明 | 当前数量 |
|---|---|---|
| 框架图 framework | 方法总览、模块结构、数据流 | 12 |
| 动机图 motivation | 提出问题：现有方法为何失效 | 6 |
| 实验·定量 quantitative | 折线/柱/散点/雷达/热力图 | 10 |
| 实验·定性 qualitative | 检测框、分割掩码、注意力图、检索结果 | 8 |
| 绘图样式 style | 期刊偏好的配色与字体方案 | 24 |

## 二、框架图（12）

覆盖算法类与体系结构类两条线：

| 模板 | 适用 |
|---|---|
| 单流 Pipeline | 输入→骨干→模块→头，通用骨架 |
| 双分支（双流） | 图文/音视双编码器 + 跨模态融合 |
| 编码-解码 + 对称跳跃 | U 形结构，分割/去噪 |
| 主干 + 模块放大 Zoom-in | 主干画流程，下方放大单个模块内部 |
| 多阶段级联 | Stage 串联 + 逐级精修反馈 |
| 图结构 + 消息传递 | 异构节点/边 + GNN |
| 自注意力（Q/K/V） | Transformer 类 |
| MoE 路由 + 多专家 | 稀疏专家模型 |
| 量化流程（STE） | 量化/部署类 |
| 剪枝流程（迭代回路） | 剪枝/压缩类 |
| 知识蒸馏（教师-学生） | 蒸馏类 |
| 硬件数据流（脉动阵列） | MICRO/HPCA/ISCA/ASPLOS |

全部用 TikZ 画，矢量、可直接编译进论文。

## 三、动机图（6）

`差距对比柱状图`、`失败案例拼图`、`精度-代价散点`、`注意力分布对比`、`规模-收益曲线`、`分布漂移示意`。

共同点：**必须在第一眼说清"问题在哪"**，通常配合一句 caption 直接点题。

## 四、实验图 · 定量（10）

`收敛曲线`、`消融柱状`、`误差带`、`雷达图`、`热力图`、`小提琴图`、`帕累托前沿`、
`分组柱（hatch）`、`超参敏感性`、`累积成功曲线`。

注意事项：
- 多种子画误差带/小提琴，不要只报最优一次
- 黑白打印用 hatch 或线型区分，别只靠颜色
- 帕累托前沿是"非支配点"的包络，不是随便连线

## 五、实验图 · 定性（8）

`检测结果网格`、`分割掩码对比`、`注意力热图`、`检索 Top-K`、`失败案例`、
`超分/复原对比`、`深度图`、`视频关键帧`。

模板里的"照片"是程序合成的占位图，代码里换成你自己的图片路径即可。

## 六、会议标签

CVPR / ICCV / ECCV / NeurIPS / ICML / ICLR / ACL / EMNLP / AAAI /
DAC / MICRO / HPCA / ISCA / ASPLOS / MLSys / TPAMI / TCAD / ACM MM / MICCAI / ICRA。

一个模板可以标多个会议——因为同一套画法在不同会议反复出现，
**合并成一个条目、标注多个会议**比按会议拆成十几份更有用。

## 七、领域标签

通用 / LLM / 多模态 / 检测 / 分割 / 生成 / 量化 / 剪枝 / 蒸馏 / 系统 / RL。

## 八、怎么加新图

1. 在 `tools/figlab/` 里加一个生成函数
2. 注册到对应模块的 `TEMPLATES`
3. 跑 `.venv-fig/bin/python tools/figlab/build.py --only <组名>`
4. `node tools/build-data.mjs` 重建数据
