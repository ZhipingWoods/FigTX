# 贡献指南

## 贡献一个样式

1. Fork 仓库并新建分支
2. 把你的 LaTeX 片段放到 `data/latex/<your-id>.tex`
3. 在 `data/raw-items.json` 里加一条记录：

```json
{
  "id": "your-id",
  "kind": "table",
  "title": "你的样式名",
  "caption": "样例 caption",
  "latex": "...全文...",
  "latexFile": "data/latex/your-id.tex",
  "palette": ["#EEF2F5"],
  "venues": ["CVPR"],
  "year": 2026,
  "images": []
}
```

4. 生成预览图与数据：

```bash
python3 tools/render_tex.py --items data/raw-items.json --only your-id --out public/renders
node tools/build-data.mjs
npm run build
```

5. 提 PR，附一张渲染截图

## 代码规范

- TypeScript，`npx tsc --noEmit` 必须通过
- CSS 用 `src/styles.css` 里的设计变量，不要写死颜色
- 提交信息用 `feat:` / `fix:` / `docs:` 前缀

## 报告问题

渲染失败请附：样式 id、tectonic 报错、`data/latex/<id>.tex` 内容。
