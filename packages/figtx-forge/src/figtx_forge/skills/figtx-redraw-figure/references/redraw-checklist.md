# 一比一复刻逐项检查清单

每轮 `figtx redraw-check` 后按顺序过一遍，前一项没过不要急着修后一项。

1. **文字**：`missing_texts` 为空；每段文字的字号、粗细、颜色、对齐与原图一致；没有错别字、漏掉的上下标、撇号（x′）。
2. **结构**：heatmap 上没有成块的红色（漏画的框/线/图标）；没有成块的蓝色（多画的东西）。
3. **位置**：红蓝成对、平行出现 = 画偏了。量原图坐标重新写，不要凭感觉挪。
4. **尺寸**：框的宽高、圆角半径、线宽与原图一致（线宽可在 1/1.5/2/3 px 之间对比 heatmap 选最贴近的）。
5. **颜色**：color_similarity 不达标时，逐个容器取色核对 fill/stroke。浅色底色最容易被忽略。
6. **线型**：虚线/实线、箭头方向、箭头在起点还是终点。
7. **位图**：抠图只用于照片/渲染/复杂插画；占比 ≤ 40%（照片为主的图用 `--allow-photo-heavy`）。
8. **lint**：无 `text-overflow`、无 `out-of-canvas`。

## 反目标（出现即不合格）

- 整页或整个面板贴成位图。
- 场景里出现原图没有的文字、模块、图标。
- 文字转成了路径或图片。
- 分数不达标却对用户说「已完成一比一复刻」。

## 门槛（与 FigTX 贡献审核一致）

composite ≥ 0.98 · dark_recall ≥ 0.98 · local_recall ≥ 0.97 · edge_f1 ≥ 0.97 · color_similarity ≥ 0.98 · 文字完全一致 · 位图占比 ≤ 40%（照片为主 ≤ 85% 并注明）
